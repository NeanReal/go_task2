# Расчёт количества дней до нового года
Приложение создано для расчёта количества дней до нового года от заданной даты, либо от текущей даты пользователя.
## Требования
Для запуска приложения необходимо наличие Go версии 1.22 и выше.
## Установка и запуск
Запуск напрямую: `go run .` или `go run main.go`

Сборка бинарника: `go build -o app .` и его последующий запуск `./app`

По умолчанию сервис запускается на `http://localhost:8080`
## Тестирование
Для запуска тестов надо выполнить команду: `go test -v ./...`

(флаг -v полезен, чтобы видеть подробный статус каждого сценария).
## Документация API

Сервис предоставляет HTTP эндпоинт для вычисления количества дней до наступления Нового года.

### `GET /api/calc`

Выполняет расчёт количества дней от заданной даты или от текущего момента.

#### Входные параметры (Query Parameters)

| Параметр | Тип | Обязательный | Формат | Описание |
| :--- | :--- | :---: | :--- | :--- |
| `date` | `string` | Нет | `YYYY-MM-DD` | Дата, относительно которой выполняется расчёт. Если параметр не указан, расчёт производится относительно текущей даты сервера. |

---

#### Примеры запросов

**1. Запрос без указания даты (расчёт от текущей даты):**
```bash
curl http://localhost:8080/api/calc
```

**2. Запрос с указанием конкретной даты:**
```bash
curl "http://localhost:8080/api/calc?date=2026-12-25"
```

**3. Запрос с некорректным форматом даты:**
```bash
curl "http://localhost:8080/api/calc?date=invalid-date"
```

---

#### Формат ответа

##### Успешный ответ (`200 OK`)
* **Content-Type**: `application/json; charset=utf-8`
* **Поля JSON-ответа:**
  * `date` (`string`, RFC 3339 / ISO 8601) — дата, относительно которой производился расчёт.
  * `title` (`string`) — текстовое описание (`"Дни до Нового года"`).
  * `days_to_new_year` (`integer`) — количество оставшихся календарных дней до 1 января следующего года.

Пример ответа:
```json
{
  "date": "2026-12-25T00:00:00Z",
  "title": "Дни до Нового года",
  "days_to_new_year": 7
}
```

##### Ответ при ошибке в данных (`400 Bad Request`)
* **Content-Type**: `text/plain; charset=utf-8`
* Возвращается при передаче невалидной даты или неверного формата:
```text
Неверный формат даты. Ожидается YYYY-MM-DD
```

##### Ответ при неподдерживаемом HTTP-методе (`405 Method Not Allowed`)
Возвращается автоматически при попытке обратиться к эндпоинту методом, отличным от `GET` (например, `POST`, `DELETE`):
```text
Method Not Allowed
```
